#### ⭐ `KAYORA` — Intelligent Aquatic Biomass Recovery & Circular Processing System
> **`Recover. Restore. Reuse.`**
* An AI-assisted sustainability platform designed to detect, track, and clear invasive aquatic weeds from inland water bodies.
* Merges computer vision monitoring with semi-autonomous harvesting, transforming recovered aquatic biomass into eco-friendly biodegradable packaging, mats, and structural biomass boards.
* **Stack:** `Python` • `Computer Vision` • `IoT / Edge Sensors` • `AI Classification` • `Circular Bio-Engineering`

#### ⭐ `RiverClean` — AI-Powered River Pollution Monitoring
> **Team Lead**
* An intelligent computer vision web platform developed to detect, categorize, and quantify floating river pollution from user-submitted imagery.
* Translates raw visual data into actionable environmental metrics to help local authorities and conservation teams coordinate clean-water interventions.
* **Stack:** `Python` • `PyTorch` • `OpenCV` • `FastAPI / Flask` • `React.js` • `Docker`
